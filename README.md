# ثبت نام خودکار بهستان

یک ابزار خودکار برای ثبت نام دروس دانشگاه تهران (سامانه بهستان) با قابلیت حذف و اضافه.

## دو فاز اجرا

این برنامه در دو فار اجرا میشود:
1-فاز ثبتنام اصلی: برای شروع انتخاب واحد که هدف فقط ثبتنام در درس و گروه مورد نظر است.

2- فاز حذف و اضافه: در این فاز هدف بررسی جاهای خالی برای یک درس و چنذین گروه است تا در صورت پیدا شدن جای خالی ثبتنام در ان صورت بگیرد.

### فاز ۱: ثبت‌نام اصلی (`HAZF_EZAFE = False`)

بدون بررسی ظرفیت، مستقیماً گروه درسی را ثبت‌نام می‌کند و مدام تکرار می‌کند. برای لحظه باز شدن ثبت‌نام اصلی. (جزئیات بیشتر در بخش `lesson.json`)

### فاز ۲: حذف و اضافه (`HAZF_EZAFE = True`)

به صورت دوره‌ای ظرفیت گروه‌ها را از سامانه می‌گیرد و هرکدام جا خالی داشت ثبت‌نام می‌کند. (جزئیات بیشتر در بخش `lesson.json`)

## تنظیمات

### 1. فایل `variable_config.py`

| متغیر | توضیح |
|-------|-------|
| `USER` | نام کاربری سامانه بهستان |
| `PASSWORD` | رمز عبور سامانه بهستان |
| `STUDENT_NUMBER` | شماره دانشجویی |
| `TERM` | کد ترم (پیش‌فرض: 4042) |
| `FID` | کد فرم ثبت نام |
| `HAZF_EZAFE` | `False` برای ثبت‌نام اصلی، `True` برای حذف و اضافه |

مقادیر `FID`:
- `12100` - ثبت نام اصلی
- `12370` - ترمیم
- `12140` - حذف اضطراری

### 2. فایل `lesson.json`

لیست دروس مورد نظر برای ثبت نام. ساختار هر درس به این صورت است:

```json
"<کد_درس>": {
    "ac":  <1 ,3 ,4 ,5>,
    "fil": "<i یا e>",
    "lst": ["<گروه1>", "<گروه2>", ...]
}
```

| فیلد | توضیح |
|------|-------|
| **کد درس** | کلید اصلی، همان کد درس  در سامانه بهستان |
| **`ac`** | نوع درخواست: `1` ثبت‌نام، `3` لیست انتظار، `4` حذف درس، `5` تغییر گروه |
| **`fil`** | نوع فیلتر گروه‌ها — `i` یعنی فقط گروه‌های داخل `lst` را چک کن، `e` یعنی همه گروه‌ها را چک کن به جز گروه‌های داخل `lst` |
| **`lst`** | لیست کد گروه‌های درسی (مقادیر `g` در سامانه) |

---

#### رفتار `lesson.json` در هر فاز

##### فاز ۱ — ثبت‌نام اصلی (`HAZF_EZAFE = False`)

در این فاز برنامه **فقط اولین عنصر `lst`** را به عنوان گروه درسی در نظر می‌گیرد و مستقیماً همان را ثبت‌نام می‌کند. فیلد `fil` در این فاز **نادیده گرفته می‌شود**.

```json
{
    "1120018": {"ac": 1, "fil": "i", "lst": ["37"]}
}
```

در مثال بالا، برنامه مدام درس `1120018` را در گروه `37` ثبت‌نام می‌کند. نیازی به نوشتن چند گروه در `lst` نیست چون جستجویی انجام نمی‌شود.

##### فاز ۲ — حذف و اضافه (`HAZF_EZAFE = True`)

در این فاز برنامه از سامانه لیست تمام گروه‌های هر درس را دریافت می‌کند، ظرفیت‌ها را بررسی کرده و فقط گروه‌هایی که `rc < dc` (ظرفیت خالی دارند) را ثبت‌نام می‌کند.

**فیلتر `i` (include):** فقط گروه‌هایی که در `lst` هستند را بررسی کن:

```json
{
    "1120018": {"ac": 1, "fil": "i", "lst": ["37", "35", "36"]}
}
```

یعنی برای درس `1120018` فقط گروه‌های `37`، `35` و `36` را چک کن و هرکدام جا داشت ثبت‌نام کن.

**فیلتر `e` (exclude):** همه گروه‌ها را بررسی کن به جز گروه‌های داخل `lst`:

```json
{
    "8120013": {"ac": 7, "fil": "e", "lst": ["21"]}
}
```

یعنی برای درس `8120013` همه گروه‌ها را چک کن به جز گروه `21`.
